# Hospital — электронные медицинские карты

Учебное веб-приложение на C# / ASP.NET Core (.NET 10) для учёта пациентов,
отделений, назначений и выписки из стационара.

## Возможности

- госпитализация пациента (ФИО, отчество, дата рождения, пол, контакты);
- проверка даты рождения — она не может быть позже сегодняшней;
- направление пациента в отделение к лечащему врачу;
- назначение процедур, инъекций, таблеток и обследований;
- отметка выполнения назначений врачом или медсестрой;
- выписка пациента с формированием выписного эпикриза;
- печать бланка выписки без элементов интерфейса.

## Запуск

Требуется .NET SDK 10.

```bash
dotnet run --project Hospital.Web
```

Приложение откроется по адресу http://localhost:5000.

## Структура

- `Hospital.BusinessObjects` — бизнес-объекты и правила валидации;
- `Hospital.DataLayer` — JSON-хранилище и интерфейсы доступа к данным;
- `Hospital.Services` — сервисы приложения и DTO;
- `Hospital.Web` — ASP.NET Core REST API и веб-интерфейс.

Данные хранятся в JSON-файлах в `Hospital.Web/Data`. При первом запуске
справочники отделений и сотрудников создаются автоматически.
